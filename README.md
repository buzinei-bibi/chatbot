🤖 bot do telegram

um bot simples desenvolvido em python para o telegram.

💬 sobre

o bot foi criado como um exercício para praticar a criação de bots em python e a integração com serviços de inteligência artificial.

ele é capaz de receber perguntas e mensagens enviadas pelo usuário e gerar respostas utilizando inteligência artificial.

⚙️ como funciona

1. o usuário envia uma mensagem para o bot pelo telegram.
2. o bot recebe a mensagem.
3. a pergunta é enviada para a inteligência artificial.
4. a ia gera uma resposta.
5. o bot envia a resposta de volta para o usuário.

🧠 inteligência artificial

o bot utiliza um modelo de inteligência artificial da groq para processar as perguntas e gerar as respostas.

📱 telegram

a comunicação com o usuário é feita através do telegram, permitindo que as mensagens sejam enviadas e respondidas automaticamente.

📚 objetivo

o objetivo principal foi praticar conceitos de:

- 🐍 python
- 🤖 criação de bots
- 💬 comunicação com o telegram
- 🧠 integração com inteligência artificial
- 🔗 integração entre diferentes serviços
